# orgmemory

Part of [Memory Lab](https://github.com/timothyzhbw-jpg/memory-lab#readme). Verified Organizational
Memory: the `orgmemory` command replays an organizational decision log under explicit authority rules,
explains why a subject is in its current state with quoted evidence, audits the decision process,
imports GitHub issues and pull requests, and imports saved Jira Cloud search captures. See the root README for usage and the
[changelog](https://github.com/timothyzhbw-jpg/memory-lab/blob/main/CHANGELOG.md) for changes.
