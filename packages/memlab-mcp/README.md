# memlab-mcp

Part of [Memory Lab](https://github.com/timothyzhbw-jpg/memory-lab#readme). A read-only MCP server that
exposes MemFalsify and Organizational Memory to local agents, with every path confined to one root
directory. See [docs/mcp.md](https://github.com/timothyzhbw-jpg/memory-lab/blob/main/docs/mcp.md) for
usage and the [changelog](https://github.com/timothyzhbw-jpg/memory-lab/blob/main/CHANGELOG.md) for
changes.
