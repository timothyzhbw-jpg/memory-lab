# Logo

| File | Use |
|---|---|
| `logo.png` | Lockup for light backgrounds (teal mark, navy wordmark) |
| `logo-dark.png` | Same lockup for dark backgrounds (wordmark in #F0EEE6) |
| `logo-icon.png` | The mark alone, square, for avatars and favicons |

All three have transparent backgrounds. The logo was generated with GPT Image from this brief: an M-shaped
path suggesting a memory timeline, ending in a small check, next to the wordmark "Memory Lab"; flat, teal mark
and dark navy wordmark, no gradients or shadows.
