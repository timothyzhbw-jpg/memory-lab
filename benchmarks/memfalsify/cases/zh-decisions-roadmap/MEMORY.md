# 项目记忆：报表产品

## 发布计划

- 批量导出会跟随 11 月版本一起上线。
- 批量导出上线前需要先过隐私评审。
- 所有新功能上线前都要经过隐私评审。
- 2026年3月2日：协作空间推迟到第三季度。
- 协作空间目前还在内测，尚未正式发布。
- 新版首页已经向一成的网页端用户开放。
- 新版首页的移动端灰度比例是 10%。
- 断网的时候也能新建报表草稿。

## 定价与套餐

- 老客户从2026年11月1日起也要按 129 元付费。
- 企业版月费将上调到 399 元。
- 免费用户也可以使用基础模板。
- 免费版的存储额度会提高到 5GB。
- 大客户似乎更倾向于按年付费。

## 路线图方向

- 接下来两个季度的工作重点是报表加载性能。
- 报表首屏加载的目标是三秒以内。
- 路线图评审批准了第三方插件市场。
- 报表导出 PDF 的排版问题明年交给设计组处理。
- 客户对新版筛选器的评价很好，NPS 涨到了 42。
