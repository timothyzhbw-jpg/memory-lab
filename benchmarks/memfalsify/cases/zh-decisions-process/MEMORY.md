# 研发管理记忆

## 采购

- 所有采购都需要财务审批。
- 超过 5 万元的采购还需要 CTO 签字。
- 提交采购申请时要附三家供应商的报价。

## 代码评审

- 代码合并前至少需要两人审查。
- 改动支付模块的代码非得两个人评审通过才能合并。
- 新的代码评审规范执行得非常顺利。

## 发布与封版

- 封版期间禁止任何上线。
- 封版期间上线不仅要是 P0 修复，而且要 CTO 审批。
- 2026年10月12日起恢复正常发布节奏。

## 人员与预算

- 第四季度不招前端了。
- 后端新增的 2 个名额都给支付组。
- 远程办公的日子可以自己选，没有固定的到岗日。
- 2025年12月18日：2026年研发预算定为1200万元。
- 2026年研发预算一共是1200万元。
- 2026年云资源费用的上限已经上调到 550 万元。
- 云资源超支估计主要是 GPU 训练任务导致的。

## 工具

- 未来一年内会把代码仓库从 GitLab 迁到自建 Gitea。
- 新的代码评审规范执行得非常顺利。
