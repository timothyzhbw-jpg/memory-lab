# 航标容量与重试记忆

<!-- 虚构评测数据：航标是虚构公司。 -->

## 时延与错误预算

- 检索的九九分位时延必须压在四分之一秒以内。
- 账单服务的 p99 时延预算是四分之一秒。
- 下单接口的返回时限是 2 分钟。
- 检索服务每月的错误预算是请求量的千分之一。
- 检索服务每个月允许百分之一的请求失败。

## 存储与保留

- 检索索引的热数据有半个太比字节。
- 检索索引的热数据占用五百一十二吉比字节。
- 检索索引的热数据占了 512 GB。
- 账单归档有 500 GiB。
- 检索热数据保留 90 天。
- 检索热数据目前保留 30 天。
- 2026年3月2日容量组曾打算让检索热数据保留三十天。

## 超时、重试与告警

- 账单渲染的网关超时是 1500 毫秒。
- 所有网关超时都是 1500 毫秒。
- 已经成功的检索查询不得再发一次。
- 检索查询成功之后已经不再重试。
- 账单渲染不得重试。
- 账单渲染只有第一次返回 HTTP 503 时才能重试。
- 账单值班不得确认检索告警。
- 检索值班不得确认账单告警。
