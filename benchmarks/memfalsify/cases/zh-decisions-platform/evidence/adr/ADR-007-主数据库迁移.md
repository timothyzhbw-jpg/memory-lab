# ADR-007 主数据库迁移到 PostgreSQL

状态：已采纳（2026年8月20日架构委员会通过）

## 背景

主库目前运行 MySQL 5.7，官方支持已经结束，JSON 查询和全文检索的性能也无法满足报表需求。

## 决定

将主库由 MySQL 5.7 迁移至 PostgreSQL 16。
迁移期间采用双写，订单库和用户库分别迁移，先迁用户库。
计划在2026年第四季度完成切换。
切换窗口必须避开每月最后三个工作日的财务结账期。
切换后 MySQL 只读副本保留30天，用于对账和必要时回滚。

## 备选方案

- 升级到 MySQL 8.0：改动最小，但不能解决全文检索的问题。
- 引入独立的搜索集群：运维成本高，本次不采用。
