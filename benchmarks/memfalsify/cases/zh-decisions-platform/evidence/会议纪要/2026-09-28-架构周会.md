# 架构周会纪要

- 日期：2026年9月28日
- 参会：平台组、DBA 组、SRE

## 数据库迁移

由于 PostgreSQL 扩展的兼容性测试延误，主库切换从第四季度推迟到2027年第一季度。
用户库的双写已经上线，订单库的双写预计11月开始。
迁移演练由 DBA 组负责排期。

## 网关

从10月起，新上线的对外服务必须接入统一 API 网关，内部服务暂不强制。

## 日志与消息

有同事提到 Kafka 在日志采集场景的吞吐更高，日志采集链路的改造后续再评估。
日志平台的存储选型（Elasticsearch 还是 ClickHouse）放到下个季度再讨论。
消息队列本季度继续使用 RabbitMQ，不做调整。
