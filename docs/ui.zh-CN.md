# Memory Lab 网页

[English](ui.md) | 中文

`memlab-ui` 是一个在本机运行的只读网页，不用学命令行就能试用 MemFalsify 和 orgmemory。它只读取一个项目文件夹，
从不修改任何文件。它调用的库代码与 `memfalsify`、`orgmemory` 命令相同，路径限制规则与 [MCP 服务器](mcp.zh-CN.md)
一致。

## 安装与运行

在本仓库的检出目录中：

```bash
pip install -e packages/memcore -e packages/memfalsify -e packages/orgmemory -e packages/memlab-ui
memlab-ui --root examples
```

`./scripts/setup-local.sh` 也会安装它。命令会打印要打开的地址，默认是 `http://127.0.0.1:8765/`。按 Ctrl+C 停止。

| 选项 | 含义 |
|---|---|
| `--root DIR` | 网页可以读取的项目文件夹（默认是当前目录）。不会读取它之外的任何内容。 |
| `--port N` | 127.0.0.1 上的端口（默认 8765；`0` 表示选一个空闲端口并打印出来）。端口被占用时以退出码 2 结束。 |
| `--host HOST` | 只接受 `127.0.0.1`，其他值以退出码 2 结束：网页没有登录，不能让其他机器访问。 |
| `--allow-model-verifiers` | 在“更多选项”中提供 `llm`、`jev`、`dual` 和 `cascade` 验证器。它们会把记忆和证据文本发送给外部 API 并产生费用；密钥设置见 [local-setup.zh-CN.md](local-setup.zh-CN.md)。 |

每个页面都有英文和简体中文两种语言。`?lang=zh` 选择中文；链接和表单会保留所选语言，侧栏底部的“English / 中文”
链接可以在同一页面上切换。

## 页面

表单都使用 GET，所以每个结果都有自己的地址，可以刷新或收藏，任何请求都不会改变任何东西。

### 首页

介绍 Memory Lab 是什么；“要检查哪个文件？”框一步把一个文件与整个项目对照；“本项目中的智能体文件”列出
`memfalsify discover` 找到的文件（CLAUDE.md、AGENTS.md、GEMINI.md，以及 Cursor、Copilot、Windsurf 规则）
和所有 `MEMORY.md`，并给出每个文件的陈述数量。

### 检查智能体文件

选择“智能体文件”和“对照范围”：整个项目（默认）或某一个文件夹。“更多选项”包括：

- “只看此后改动的陈述”：一个分支、标签或提交。页面随后运行 `memfalsify diff`，只检查该修订之后新增或改动的
  陈述，未改动的不再重新检查。只有当根文件夹是 git 仓库的顶层时才提供；与 MCP 工具一样，仓库的工作区、git 目录、
  公共目录和对象库都必须位于根文件夹之内。
- “把今天当作”：判断文件中旧日期的基准日期（`--as-of`）。
- “审阅文件”：记录了人工确认的 `reviews.jsonl`。其中的路径必须指向对照范围内的文件。
- “对照方式”：只有加上 `--allow-model-verifiers` 时才出现。

结果就是用平实语言呈现的 `memfalsify audit` 报告：

| 卡片 | 状态 |
|---|---|
| “请看这些” | `challenged`、`conflicted`、`candidate_counterevidence`（可能的反证）、`disputed` |
| “大概没问题” | `supported`、`candidate_support` |
| “无法判断” | `insufficient_evidence` |

每条需要查看的陈述是一张卡片：“你的智能体文件写道”及其 `路径:行号`，旁边是“你的文档写道”和看起来有出入的引文，
不同的词语或数字会被高亮（仅限词法验证器自己的匹配），并说明为什么被标出、来源文件 SHA-256 的前 12 个字符，以及
一句建议。之后是更多来源、措辞问题（“总是”“下周”、猜测、重复）和陈述 ID。其余陈述折叠在“显示其余 N 条陈述”下，
未参与对照的文件折叠在“N 个文件未读取”下。最后的说明指出快速检查比较的是词语：它可能漏掉换了说法的来源，也可能
标出只是看起来矛盾的句子。

### 团队决策

选择一个“决策日志”：根文件夹下任何包含 `events.jsonl`、`policy.json` 和 `evidence.jsonl`（以及可选的
`policy-log.jsonl`）的文件夹。“更多选项”可以查看截至某一天结束时（UTC）的状态。

- 侧栏列出日志中的主题（subject）及其状态：“已批准”“已拒绝”或“待定”（`proposed`）。
- 横幅显示有多少处需要注意：即 `orgmemory audit` 的发现（超过 14 天视为停滞，以所选日期或当前时间计算）。
- 对于所选主题：谁以什么角色在何时作出决定，决定依据的引文，正在等待什么，未解决的风险和依赖，用平实语言写出的
  发现，以及“事情经过”：按回放顺序列出的每个事件及其引文，标为“算数”（有权限的决定）、“已记录”（有权限的请求、
  风险、依赖或评论）或“不算数”（例如“account manager无权批准”）。
- “两个日期之间的变化”对第一个日期结束之后、到第二个日期结束为止（UTC）的事件运行 `orgmemory changes`。

## 安全

网页遵循 [MCP 服务器](mcp.zh-CN.md)的规则，并针对浏览器做了调整：

- **只监听本机回环地址。** 绑定 127.0.0.1，拒绝其他任何 `--host`。来自其他地址的请求会被拒绝。
- **防 DNS 重绑定。** 每个请求必须恰好带一个 `Host` 头，内容是 `127.0.0.1` 或 `localhost` 加上服务器端口；
  其他情况返回 403，且不回显该头部。其他网站即使把自己的域名解析到 127.0.0.1，也拿不到任何内容。
- **只读。** 只响应 GET 和 HEAD（其他方法返回 405），所有表单都用 GET，没有页面会写报告、追加事件、记录审阅或
  应用补丁。git 以 `GIT_OPTIONAL_LOCKS=0` 运行，也不会刷新索引。测试会在访问每个页面前后对根文件夹做快照比较。
- **路径限制。** 请求中的每个路径都在 `--root` 内解析：相对路径可以，绝对路径只有在根文件夹内才可以；`..` 和
  符号链接只有在解析结果仍在根文件夹内时才可以。隐藏文件和文件夹、`node_modules`、`__pycache__` 和 `venv` 都会被
  拒绝，`.cursor/rules/` 这类有文档说明的智能体指令位置除外。每个页面都在 `memcore` 的受限读取中运行，所以检查之后
  被替换成向外符号链接的文件，在打开时仍会被拒绝。没有 POSIX `O_NOFOLLOW` 和 `dir_fd` 支持（Windows）时，服务器
  拒绝启动。表单提供的列表来自同一次遍历，并跳过嵌套的 git 仓库和符号链接文件夹。
- **默认关闭模型验证器。** 默认使用离线的词法验证器。除非用 `--allow-model-verifiers` 启动，否则请求 `llm`、
  `jev`、`dual` 或 `cascade` 都返回 403。
- **不可信文本始终是文本。** 记忆、证据、文件名、审阅、事件日志、策略名称和来源 URI 都经过 `memcore.htmlpage`：
  转义处理，控制字符、双向文本字符和其他不可见字符显示为 `U+XXXX`。只有 `http` 和 `https` 来源会成为链接。
  文档是 7 位 ASCII。
- **严格的响应头。** `Content-Security-Policy: default-src 'none'; img-src 'self'; style-src 'unsafe-inline';
  form-action 'self'; base-uri 'none'; frame-ancestors 'none'`（不含 `frame-ancestors` 的同一策略也写在 meta 标签
  中），以及 `X-Content-Type-Options: nosniff`、`X-Frame-Options: DENY`、`Referrer-Policy: no-referrer` 和
  `Cache-Control: no-store`。没有 JavaScript、没有 Cookie、没有外部资源：样式内联，图标是内联 SVG，字体用系统
  字体，唯一的图片是从软件包中按确切文件名在 `/static/` 下提供的标志和网站图标。
- **出错时不泄露细节。** 错误只是一句话，从不包含堆栈跟踪、根文件夹之外的路径、git 自己的诊断信息或被拒绝文件的
  内容；根文件夹之外的值也不会显示回表单中。终端日志每个请求一行：方法、已知路由或 `-`、状态码，从不记录查询
  参数或请求头。

## 局限

- 没有登录。同一台电脑上的其他程序和其他用户都可以打开这个地址，读取页面从根文件夹中显示的内容。请在不与他人共用
  的电脑上运行，或者选择一个愿意展示的根文件夹。
- 其他浏览器标签页里的网页可以让你的浏览器向服务器发送 GET 请求，从而让它运行检查，但读不到结果，而且任何请求都
  不会改变任何东西。
- 网页不保存报告。要分享报告，请用 CLI 的 `--format html`。
- 列表最多遍历 5000 个文件夹，“对照范围”中提供的文件夹最多四层深。
- 中文页面上的小字库细节（发现详情、跳过原因）仍是英文。
